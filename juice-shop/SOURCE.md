# Origem do ambiente Juice Shop

Este projeto incorpora somente a configuração de execução local (Docker Compose, scripts de setup e documentação operacional) do repositório:

- Repositório: https://github.com/yhsww/juice-shop
- Branch de origem: `main`
- Commit de origem no momento da incorporação: `b6bc9a5d7b72b0bb90cc8a71e967080388b32c79`
- Imagem Docker fixada: `bkimminich/juice-shop:v20.3.0`

O código-fonte completo do OWASP Juice Shop não foi copiado para este repositório. A aplicação é obtida da imagem Docker oficial fixada acima. Para atualizar a configuração, compare-a com o repositório de origem e registre o novo commit de referência.
